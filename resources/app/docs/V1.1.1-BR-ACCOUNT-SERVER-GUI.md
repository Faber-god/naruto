# Naruto-Windows v1.1.1 — BR account mapping and server selection

## What changed

The existing **Settings → Login Profiles → Edit** dialog now includes a Brazil-region session recovery section.

- Lists official Naruto Online CEF profile folders found under the default `APPDATA\\Naruto Online\\Browers\\Cache` location.
- Lets the user map each Naruto-Windows BR profile to one exact official CEF account folder.
- Supports automatic account selection only when exactly one official CEF profile is detected.
- Provides a refresh button to rescan official CEF profiles.
- Adds a numeric BR server ID selector (1–99999). Enter the numeric part only: for `S810`, enter `810`.
- Saves the mapping to the existing `br-session-recovery.json` in the app user-data directory. No manual JSON editing is required for normal use.
- Shows the selected server and account mapping in the profile list and lobby profile picker.
- Selecting “Do not enable official session recovery” removes that profile's mapping and leaves the existing login flow available.

## How to use

1. Sign in to the target BR account in the official Naruto Online client.
2. Exit the official client completely so its CEF Cookies database can checkpoint.
3. Open Naruto-Windows → Settings → Login Profiles.
4. Edit an existing BR profile, or create a new BR profile.
5. In **Official client account**, select the exact account folder shown by the scanner. If exactly one account is detected, automatic matching is also available.
6. In **BR server ID**, enter the numeric server ID shown by the official server selection page. Example: `S810` → `810`.
7. Save. The profile list will show the configured server and official account mapping.
8. Start that BR profile. The existing recovery flow fetches and validates the signed entry before importing cookies into the existing Electron game session.

## Important notes

- This build does not bundle an authoritative live BR server catalogue. It therefore uses a validated numeric server ID control instead of inventing server names or server choices. Use the actual ID shown by the game.
- The account scanner displays CEF profile folder names only. It does not display, export, or send cookie values to the renderer.
- If multiple official CEF profiles exist, choose one explicitly. Automatic matching is disabled unless exactly one profile is detected.
- The mapping is stored per Naruto-Windows profile ID; different BR profiles can map to different official CEF accounts and server IDs.
- This is a patch to the packaged v1.1.0 release bundle, not a rebuild from the original TypeScript source tree.
- Electron 11.5.0, Chromium 87, the existing BrowserView game host, PPAPI Flash runtime, and game preload files are preserved.
- Static syntax and package checks do not replace a live Windows test. Re-test account discovery, save/reload, BR session recovery, Flash rendering, and reconnect on the target PC.
