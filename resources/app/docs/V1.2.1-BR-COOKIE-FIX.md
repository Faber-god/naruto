# Naruto-Windows v1.2.1 — 本机 CEF 加密 Cookie 修复测试版

## 为什么需要修复

从用户 2026-11-02 的 errors.log 可以看出，BR 会话恢复首先出现 `BR_RECOVERY_ENCRYPTED_COOKIE_VALUES_UNSUPPORTED`，随后旧登录流程出现多次 `WEB_LOGIN_LOGIN_HTTP_403_passport`。游戏侧还出现 DNS 解析失败、连接拒绝以及 400/404，均不能单凭这些错误推断出具体资源故障。

## 本补丁变化

- 让 `dist/main/index.js` 的 BR 会话恢复和 GUI 实际使用独立文件 `dist/main/br-session-recovery.js`，修复“改了独立文件但旧内嵌代码仍被执行”的情况。
- 使用 Windows 系统 DPAPI（当前用户）在本机恢复官方 CEF 的用户保护数据：支持旧式 DPAPI Cookie，以及 Chromium `v10`/`v11` AES-GCM（如果 Local State 中存在对应的 DPAPI 包装密钥）。
- SQLite 读取器通过 `winsqlite3.dll` 读取 BLOB，保留二进制字节，并在主进程内完成 AES-GCM 校验与解密。
- 纠正 `oas_user` 可能为 `narutowebgame.com` Host-only Cookie 时前置检查与 Edge 助手不一致的问题。
- 对当前 Windows 用户无法解密的 Cookie 返回安全的错误码；不再连续打开已知被 403 拒绝的旧登录窗口。
- **不包含**绕过 Cloudflare、验证码或 Passport 的实现；这仍取决于用户本机已被官方服务认可的会话。

## 运行方式

1. 保留当前 v1.2.0 安装目录和用户数据的备份，完全退出 Naruto-Windows。
2. 优先解压 `Naruto-Windows-v1.2.1-BR-Cookie-Recovery.zip` 到一个新的测试目录。或者将小补丁包按原相对路径覆盖 v1.2.0 安装根目录。
3. 在**同一个 Windows 用户**下启动官方 Naruto Online 客户端，确认已登录正确的 BR 账号和服务器，然后正常退出客户端（包括后台进程）。
4. 启动 Naruto-Windows，检查已有的账号映射、区服编号，点击“出发”。
5. 若未成功，查看用户数据目录中的 `errors.log` 最新 `BR_RECOVERY_` 记录。不要上传 SQLite `Cookies`、`Local State`、Cookie 明文、密码或签名 URL。

## 结果说明

- `BR_RECOVERY_CEF_MASTER_KEY_UNAVAILABLE`：无法找到匹配的 `Local State` DPAPI 保护主密钥。
- `BR_RECOVERY_DPAPI_UNPROTECT_FAILED`：当前用户无法解开 DPAPI 数据（可能不是登录官方客户端时同一 Windows 用户）。
- `BR_RECOVERY_CEF_COOKIE_DECRYPTION_FAILED`：密钥存在，但 AES-GCM 验证失败或 Cookie 明文无效。
- `BR_RECOVERY_CEF_APP_BOUND_ENCRYPTION_UNSUPPORTED`：检测到新式应用绑定加密 `v20`，目前无法移植会话；应使用官方客户端的正常登录方式。
- `BR_RECOVERY_PORTAL_BLOCKED`：门户没有接受当前请求；停止，不反复绕过 Cloudflare。
- `GAME_NETWORK_OTHER_ERR_NAME_NOT_RESOLVED`：属于登录以外的游戏网络 DNS 问题，需要后续独立定位实际域名。

## 安全边界与验证状态

- 解密只在用户自己的 Windows 账号下运行；密钥和 Cookie 仅通过本机子进程管道传输，不写入日志或配置文件。
- 仅使用现有游戏允许的域名，账号映射和所选服务器 ID 仍强制校验。
- 不包含 `v20` 应用绑定 Cookie 破解、不禁用证书校验、不禁用 Electron WebSecurity。
- 当前交付依据发布包构建，**不是**以原 TypeScript 源码重新构建的正式版。
- 已执行语法检查、模拟 AES-GCM、主进程引用检查和 ZIP 完整性检查；尚未在用户的 Windows 电脑上验证 DPAPI、官方 Cookie、Edge 取签名、Flash 加载与连接错误。因此属于**真机测试版**。
- 继续保留 Electron 11.5.0、Chromium 87、BrowserView 和原有 Flash 运行时文件。
