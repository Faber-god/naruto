# Naruto-Windows 1.2.0 — Instalação simples e configuração inicial

## Instalação

1. Baixe o pacote ZIP completo.
2. Clique com o botão direito e selecione **Extrair tudo**.
3. Abra a pasta extraída e execute `Install-Naruto-Windows.bat`.
4. Pressione Enter para instalar em `%LOCALAPPDATA%\Programs\Naruto-Windows` ou informe outra pasta.
5. O instalador cria atalhos na Área de Trabalho e no Menu Iniciar. Não exige privilégios de administrador.

## Assistente inicial

Na primeira abertura, o assistente:

1. Mostra informações básicas do ambiente e do Flash incluído.
2. Permite escolher um perfil BR existente ou criar um novo.
3. Procura os perfis locais do cliente oficial Naruto Online.
4. Permite vincular uma conta oficial e informar o ID numérico do servidor BR.
5. Também permite pular a recuperação automática e usar o login normal.

O assistente sugere `810` (S810), valor padrão usado pelo projeto de referência. Confirme se corresponde ao seu servidor; se aparecer outro código, informe apenas os números. Esta versão não contém um catálogo oficial atualizado de servidores.

## Recuperação de sessão

Para usar a recuperação automática, entre na conta pelo cliente oficial e feche o cliente completamente antes de atualizar a lista. Se não houver perfil oficial detectável, selecione o login normal. O aplicativo não solicita nem transmite a senha do cliente oficial e não mostra os valores dos cookies.

## Desinstalação

Execute `Uninstall-Naruto-Windows.bat` na pasta de instalação. O programa e os atalhos serão removidos; os perfis e dados em `%APPDATA%\Naruto OS` serão preservados.

## Compatibilidade e limites

- Pacote Windows x64.
- Electron 11.5.0 / Chromium 87 / PPAPI Flash preservados.
- O assistente não altera a configuração do Flash nem o motor do navegador.
- A recuperação automática depende do formato do banco CEF, do estado da sessão oficial e da resposta do portal BR. Se falhar, use o fluxo normal de login.
- Esta distribuição contém um instalador PowerShell por usuário, não um `Setup.exe` assinado. O SmartScreen pode exibir um aviso por não haver assinatura digital.
- Testes estáticos não substituem a validação em computadores Windows reais.
