# Naruto-Windows v1.2.1 — BR 门户 Edge 直连热修补丁

本热修仅更改 `resources/app/scripts/br-portal-fetch.ps1`，适用 **Naruto-Windows v1.2.1**。无需修改账号映射或 `br-session-recovery.json`。

## 修复内容

- 专门请求 BR 门户的独立 Edge 进程增加 `--no-proxy-server`，忽略 Windows/Edge 系统代理配置。
- 保留原来的 Edge 专用用户目录、CDP、官方 CEF Cookie 读取、签名 URL 验证和 Electron/Flash 游戏宿主。
- 检测到 Cloudflare 的明确拦截页面后立即终止，不再自动刷新该页面两次。
- 只影响辅助 Edge 进程；不会关闭或修改你其他应用的代理配置，也不会替游戏 BrowserView 设置直连。

## 如何安装热修

1. 完全退出 Naruto-Windows 和它启动的 Edge 门户窗口。
2. 找到 Naruto-Windows **v1.2.1 安装根目录**（包含 `Naruto-Windows.exe` 的目录）。通过安装器默认安装的位置通常是 `%LOCALAPPDATA%\Programs\Naruto-Windows`。
3. 备份原文件 `resources\app\scripts\br-portal-fetch.ps1`。
4. 将此补丁 ZIP 中的 `resources` 文件夹解压/覆盖到程序根目录，保留相对路径；不是解压到 `resources\app` 内部。
5. 打开 Naruto-Windows，用现有 BR 账号和服务器映射点击「出发」。
6. 如果出现 `BR_RECOVERY_PORTAL_BLOCKED`，说明网站仍拒绝当前直连出口。不要继续重复请求；可以查 Cloudflare Ray ID 并联系游戏运营方。

## 重要边界

- Microsoft 官方 Edge 文档确认：`--no-proxy-server` 可覆盖系统代理设置（WinINET）。
- **如果你的代理客户端开启了 TUN 模式、全局 VPN、WFP/驱动网络重定向**，浏览器启动参数无法保证物理网络路径直连。还需在代理客户端里为 `naruto.narutowebgame.com` 设置 `DIRECT`，必要时处理 `*.narutowebgame.com`；并确保该规则优先于其他规则。
- 如果你本机的直连网络本来无法访问该门户，该热修也无法让其正常连接；不能把 TLS/443 连通误判为已经通过 Cloudflare。
- 此补丁不会解决网站主动拦截当前公网 IP、账号无效、签名入口失效、游戏资源 DNS 解析失败等其他问题。
- 本热修没有关闭证书校验、没有修改浏览器指纹、没有绕过验证码或 Cloudflare 挑战。
- Windows/Edge 和 BR 真站点尚未执行端到端验证；这是基于发布包修改并完成静态检查的测试热修。

## 回滚

退出 Naruto-Windows，把之前备份的 `br-portal-fetch.ps1` 放回原目录即可。
