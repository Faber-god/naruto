# v1.8.1 本地化实现

## 已实现

- 启动器、安装器和卸载器统一为简体中文，安装版本更新为 `1.8.1`。
- 启用 Electron 11.5.0 对应的 `zh-CN.pak`，原生菜单和对话框使用简体中文。
- 根目录补丁清单升级为 v6，24 个资源全部带 SHA-256。
- 继续使用已验证的 22 个中文 SWF，不包含 `naruto.include.swf`。
- 接入动态文本词典 `TranslatedKeyCFG.cfg`。
- 生成 AI 日志与枚举中文模板 `AILogTemplate.xml`。
- 补丁缺失、读取失败或哈希不匹配时回退官方网络资源。
- 新增本地化构建、清单刷新和审计工具。

## 构建与检查

```powershell
node scripts/localization-tool.js build-ai-log
node scripts/localization-tool.js refresh-manifest
node scripts/localization-tool.js audit
node scripts/test-patch-fallback.js
```

修改任何补丁文件后必须依次运行：

1. 对应资源的构建命令。
2. `refresh-manifest` 更新 SHA-256。
3. `audit` 确认零错误。

## 补丁边界

- 允许：已验证标准 FWS 整包、zlib 配置和 AI 日志模板。
- 禁止：整包替换 `naruto.include.swf`。
- 禁止：在未完成 ZWS 解包/回包验证前整包替换 `AIPlugin.swf` 或 `AIManageUI.swf`。
- 暂不修改已认证 API 响应和服务器直接下发的普通文本。

## 已知限制

- 当前动态词典仍是部分翻译，不能视为完整中文覆盖。
- AI 托管主界面仍是 BR 原始 ZWS 资源；本次只汉化外部日志和枚举。
- 当前 `AIPluginConfig.xml` 只包含插件装载定义，没有需要替换的葡语界面文案，因此不生成冗余补丁。
- 活动、聊天、任务、邮件、福利等缺失模块仍需增量制作。
- 每次 BR 更新后必须重新验证补丁版本、哈希、字体和业务兼容性。

## 回退

- 设置 `NARUTO_PATCHES=0` 可关闭全部补丁。
- manifest 校验失败时补丁服务自动禁用并继续使用官方网络。
- 单个文件校验失败时该路径自动回退官方网络，其他补丁继续工作。
