# v1.8.1 加载与网络优化

## 默认行为

- BR 游戏默认使用已验证的 HTTPS 代理补丁链路。
- CDP Fetch 定向替换仍为实验功能，需显式设置 `NARUTO_TARGETED_PATCH=1`。
- HTTP/2 默认关闭，需显式设置 `NARUTO_HTTP2=1`。
- 启动时并行预取无需登录的公共 CDN 资源。
- 资产缓存使用索引、原子写入和异步清理。

## 回退开关

- `NARUTO_TARGETED_PATCH=1`：测试定向替换模式。
- `NARUTO_HTTP2=1`：测试 HTTP/2。
- `NARUTO_PREFETCH=0`：禁用公共资源预取。
- `NARUTO_PATCHES=0`：关闭补丁服务。
- `%APPDATA%\Naruto-Windows\asset-cache.off`：关闭资产缓存。

## 启动指标

指标写入 `%APPDATA%\Naruto-Windows\errors.log`：

- `PATCH_ATTACH_MS`
- `GAME_PROFILE_READY_MS`
- `GAME_NAVIGATION_START_MS`
- `GAME_READY_DOM_MS`
- `GAME_READY_LOAD_MS`
- `GAME_READY_STOP_MS`
- `GAME_FLASH_100_MS`

缓存索引位于：

`%APPDATA%\Naruto-Windows\asset-cache-index.json`

补丁服务关闭或标签销毁时，`patch.log` 的 `detached` 行会记录补丁命中、缓存命中、网络请求、重试、错误、字节数和 HTTP 版本。

## 预取

预取清单位于 `patches/prefetch.json`。只允许无需登录的公共 `https` 资源；单个请求超时 8 秒，失败不会阻塞游戏。不要加入 `naruto.include.swf` 或已认证 API。

## 已验收

- 默认代理模式可正常加载；冷启动约 11.8 秒，缓存预热后约 1.8 秒。
- 实验定向拦截可命中 `mainUI`、`naruto.exui`、地图、活动、好友等补丁，但缓存回填场景仍可能卡在 0%，暂不默认启用。
- 实验 HTTP/2 在定向拦截模式下曾达到 Flash `PercentLoaded=100` 约 1.8 秒，但尚未覆盖代理回退和长时间网络稳定性，暂不默认启用。
